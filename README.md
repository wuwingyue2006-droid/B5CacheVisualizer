\# B5CacheVisualizer



暑期《计算机综合课程设计》B5：



多级 Cache 映射与替换算法可视化演示系统。



\## 开发环境



\- Windows

\- Visual Studio 2022

\- C++

\- MFC

\- Git



\## 项目目标



实现并可视化：



\- L1 / L2 Cache

\- Cache Size / Block Size 配置

\- Direct Mapping

\- Fully Associative

\- Set Associative

\- FIFO

\- LRU

\- Memory Trace

\- Hit / Miss

\- Hit Rate / Miss Rate

\- Cache Line 状态与替换过程



\## 分支约定



\- `main`：稳定版本

\- `dev`：团队集成版本

\- `feature-\*`：各成员模块开发分支

项目初始化阶段。
